# BottomSheet: liquid-оболочка; MD/TXT: выделение при прокрутке

## Применение

Архив `folio_liquid_sheet_selection_fix.zip` содержит только изменённые и новые
файлы. Распакуйте его **в существующую папку проекта Folio, рядом с pubspec.yaml**,
с заменой файлов. Не заменяйте папку проекта целиком содержимым этого архива.
Исходные ресурсы, платформенные файлы и зависимости остаются в вашем проекте.

## Внешняя оболочка BottomSheet

`FolioSheetContent` включает `GlassPanel(liquidMotion: true)`. Это общая оболочка
для Settings и File info, поэтому обе точки входа получают одинаковый материал.

В общий фасад `LiquidGlass.panel` добавлен опциональный режим `liquidMotion`.
По умолчанию другие панели остаются статичными. Новый `LiquidMotionPanel`
использует существующие `GlassShell`, `GlassMotionController` и
`GlassGeometryFrame.deformedRoundedRect`; отдельного шейдера, материала или
физического движка не добавлено.

Панель получает высоту от содержимого. Нажатие и перетягивание деформируют только
внешнюю поверхность: внутренние карточки не масштабируются и не смещаются этой
деформацией. Пассивный Listener не участвует в конкуренции распознавателей жестов,
поэтому кнопки, внутренний скролл и стандартный drag-to-dismiss остаются у своих
прежних владельцев. В ходе перетягивания координаты физики не зависят от сдвига
самого маршрута под пальцем.

Настройки Liquid motion, Blur и системное отключение анимаций учитываются
независимо. Отключение физики не перемонтирует содержимое и не заменяет материал.
При завершении жеста, отмене указателя и удалении поверхности контроллер
освобождается; изменения настроек не оставляют активное нажатие.

`FolioBottomSheet`, его переходы, safe area, ограничение высоты, закрытие, фон
маршрута и содержимое `FolioSheetCard` не изменялись. Подключение режима в
`FolioSheetContent` — единственное изменение этого файла.

## Выделение MD/TXT

У read-only списка установлен `ScrollViewKeyboardDismissBehavior.manual`:
прокрутка больше не снимает фокус с области выделения. Отдельная логика фокуса
поисковой строки не изменена.

Дополнительно отмена распознавателя касания не очищает уже существующее
выделение, пока активен touch/stylus и область сохраняет фокус. Защита стоит на
уровне `SelectableRegionState.clearSelection`, до сброса корневой геометрии и
владельцев маркеров. Фильтрация только в дочернем delegate была бы недостаточна:
она могла бы оставить подсветку без полноценного выделения и Copy.

Используется родной движок `SelectableRegion`, платформенные маркеры и лупа.
Обычный завершённый тап, новое выделение долгим нажатием, мышь, маркеры,
копирование и действительная потеря фокуса остаются нативными. Короткое
отложенное освобождение указателя не даёт `PointerUp`/`PointerCancel` снять
защиту до обработки того же события распознавателями. При смене документа
сбрасывается прежнее выделение.

Существующий механизм полного Select all / Copy для ленивого документа
сохранён; текст Markdown по-прежнему копируется без служебной разметки.

## Проверки

Выполнена только офлайн-проверка структуры исходников:

```sh
python tools/check_source_integrity.py
```

Результат: 129 Dart-файлов, 464 локальных импорта, ошибок структуры не найдено.
Отдельно выполнено побайтовое сравнение с исходным архивом: внутренние блоки
BottomSheet, оба feature-виджета, маршрут, исходные материал/контроллер,
`pubspec.yaml` и `pubspec.lock` не изменены.

**Flutter SDK и Dart SDK в среде подготовки отсутствуют. `flutter analyze`,
widget-тесты, сборка APK и визуальная проверка на устройстве НЕ запускались.**
Структурная проверка не заменяет анализатор Dart, компиляцию и runtime-проверку.

Добавлены widget-сценарии для настоящих свайпов в обоих форматах на Android/iOS,
копирования после свайпа, обычного тапа, отмены указателя, настоящей потери
фокуса, стилуса и Select all после нескольких прокруток. Отдельно добавлены
проверки размера liquid-оболочки, неизменности геометрии/состояния содержимого,
внутренних кнопок и скролла, настроек, reduced motion, нескольких указателей,
правой кнопки мыши и удаления поверхности во время нажатия. Общий набор
BottomSheet расширен для Settings и File info. Прежние reader-тесты адаптированы
к базовому SelectableRegion вместо обёртки SelectionArea, без удаления проверок.

Для проверки в вашей среде:

```sh
flutter pub get
flutter analyze
flutter test test/shared/glass/liquid_motion_panel_test.dart
flutter test test/shared/widgets/folio_bottom_sheet_test.dart
flutter test test/features/reader/text_document_selection_test.dart
flutter test test/features/reader/text_selection_scroll_regression_test.dart
flutter test test/features/reader/reader_screen_test.dart
flutter test test/features/settings/folio_settings_sheet_test.dart
flutter test test/features/settings/folio_settings_sheet_transition_test.dart
```

Для полной регрессии проекта: `flutter test`.

Ручная проверка: откройте Settings и File info; нажмите и слегка потяните
оболочку, прокрутите содержимое, переключите Liquid motion и Blur, закройте
свайпом. В длинных TXT и MD выделите слово и диапазон, прокрутите в обе стороны,
скопируйте выделение; отдельно проверьте Select all, обычный тап и переход
фокуса в поиск. На устройстве также следует оценить читаемость материала поверх
светлых/тёмных страниц и плавность движения большой поверхности.
